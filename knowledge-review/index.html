  • 落点越靠下游，证明成本越低、结论越硬，但能管到的面积越小；越靠上游覆盖面越大，却只能靠架构偏置而非证明——上游本身就是概率系统，没有形式化的抓手。
  • RSI 那条「组织级解耦」是三层并存的前置条件：只要验证层还归编排层管，下游出口再硬也只是运动员兼裁判。
确定性不会同时最大化可证明性和覆盖面——这两个量在层与层之间反向。

主线②：成本可复制性——凡是不可并行的环节，必须外置

  • 变便宜的：小尺寸矩阵乘与算力、代码生成 token、手写算子技艺、单任务内的推理技巧（B0 一族）。CED 的账本正是拿便宜的 Compute 换昂贵的 Memory。
  • 不变便宜的：HBM 带宽与显存容量（所以 890 bytes/token 是硬收益）；高保真可自适应加压的环境（RSI 明说环境工程量远超策略模型）；物理试验的真实性（不可高并发复制、代价不可逆）；功能安全认证与部署签字；以及万卡集群与闭环数据所代表的组织裁决权。
  • 合并成一条判据：自进化闭环的每一环都必须换成可并行复制、因而可变便宜的东西；凡不可并行、不可逆、需签字的环节，一律外置到刚性层，不进闭环。
  • 这条判据与「责任边界＝市场壁垒」是同一个东西的两面：不能外包的责任，恰好就是不能进闭环的那部分，也就是壁垒所在。

主线③：签字吞吐——交互频次越高，签字点必须越往上移

  • CED 给出了交互的经济学底座：低 TTFT、廉价长上下文，才能支撑 Agent 每秒多轮工具调用与沙箱自修复。交互频次从此不再是瓶颈，会显著上升。
  • RSI 与算子文同时把责任钉在人身上：物理责任不可外包，部署许可须由人类签署，事故责任不能甩给 AI。
  • 两者相遇就出现新约束：动作级的责任点数随频次线性膨胀，而人不可能每秒签一次。唯一出路是把签字从动作级上移到策略级/边界级——签一次边界，边界内的动作自动放行。
  • 这解释了昨日那条「只能定边界、不能等证据」的张力为何成立：签字吞吐不是靠更多证据提高的，是靠把签字位置抬高换来的。

三、核心认知（本轮跨篇提炼）

  • 三篇的共识是手段、分歧是落点。都要求「必须有确定性结构」，差别只在放哪一层。手段一致、落点三分，这比一致本身更有信息量：架构选择的真正自由度在落点，不在手段。
  • 选场的硬门槛可以从「可复制性」推出来。不可并行复制 → 改进循环无法自举；不可逆 → 失败不能回滚；需签字 → 频次被人的吞吐封顶。三条同时成立的场景，天然不适合做自进化的试验田，只适合做被约束的部署场。
  • 这三条恰好就是车端的画像。物理试验不可高并发复制、底盘与电机动作不可逆、安全发布需签字——所以车端对自进化既是最难的地方，也是唯一必须可证明的地方。这是 2127 与通用 Agent 研究的分水岭：别人可以靠更便宜的算力绕开，车端绕不开。
  • 「空白」与「不可达」是两个命题。RSI 把具身 L5 记为理论空白，读法通常是「抢先机」；但若可复制性门槛成立，具身 L5 可能不是暂时没做到，而是结构上不该做——真答案是把自进化限制在仿真与影子层，物理层只保留刚性出口。
  • 便宜 ≠ 可获得。算力在单价上持续变便宜，但万卡集群是资本门槛。CED 式收益（省 HBM、省带宽）属于把已有算力用得更狠，对算力稀缺方是杠杆；而算力丰沛方拿到的是更宽的路。同一份技术红利，对两种组织的含义相反。

五、认知变化

昨日把「约束前置到设计期」当成三篇共识，本轮核实后降级为其中一种落点——共识是假的，分歧是真的。
  • 修正一：共识不成立。只有 CED 把约束放进预训练第一天；RSI 放在运行期验证层，算子文放在物理出口。「前置」是三种落点里最上游的一种，不是共同结论。
  • 收紧二：从「有解」到「要选解」。昨日把「监督失去工作面」降级为有候选解的工程问题；本轮发现候选解有三个，且不能免费叠加——三层同时布防等于三层成本同时付。问题因此从「有没有解」变成「选哪个落点做主场」。
  • 新读出：签字是一种吞吐量资源。此前把责任边界当成静态划分（哪归人、哪归机）；本轮发现它受人的签字速率约束，于是边界必须做成可签一次的粗粒度，而不是逐动作审批。
  • 静默回落为记账项。零新增连续 2 天，「静默」不再承担论证功能，只记进台账；本轮的价值全部来自换轴重读，而非新素材。

六、待思考问题

  • ① 2127 harness 的约束主场放哪一层？三个落点的判据排序是什么（可证明性优先，还是覆盖面优先）？若只能押一个，押验证层是否正确——因为它既是组织级解耦的产物，又是出口断言的上游供给方？
  • ② 能否把选场判据写成三条硬门槛？「不可并行复制 / 不可逆 / 需签字」三问做成 fail-fast 清单，任一条为否则该场景不进自进化闭环。这样一份清单，够不够挡住「看起来很先进的具身自进化」这类选题？
  • ③ 签字吞吐的瓶颈怎么量化？单车每秒可接受的人工介入上限是多少？超过该上限就必须上移到边界级签字——那么边界级签字的最低充分粒度是什么（速度-距离包络线？转向角速度上限？）？
  • ④ 便宜但不获得，护城河在算法还是在算力所有权？若 CED 式红利对算力稀缺方是杠杆、对丰沛方是加宽道路，那「责任边界＝市场壁垒」是否需要一条补充：壁垒也可能是算力+数据所有权而非责任本身？
  • ⑤ 具身 L5 是空白还是结构不可达？两者的工程含义相反：前者是抢时间的窗口，后者是应当换命题（把自进化限制在仿真与影子层，物理层只留刚性出口）。判定它的第一条证据会是什么？
  • ⑥ 若三层必须并存，哪一层可以最薄？成本最小化的落点组合是否存在默认解——上游做偏置、中游做断言、下游做熔断，而只在安全攸关处加厚？
