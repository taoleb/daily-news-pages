主题一 · 安全治理的物理实体化：ROSS Harness 五层实践

来源：08-27/08-28《ROSS Harness 安全治理五层实践》（灵犀智涌，机器之心两篇报道拆解；公司 PR 口径，无第三方审计）
本质一句话：安全不做在模型"心中"，做在模型"出口"——默认模型可能给出"看似合理但物理危险"的动作。
  • 第 1 层 · 模型侧安全增强：Safe-BeAl（规划与执行间加安全评估与对齐）、VLA-Stem（不改原 VLA 模型、外部附加轻量安全层——模型升级/换基座不影响安全层）、CLMASP（语义理解 + 形式化逻辑校验，把开放式概率推理转成确定可执行的任务序列）。防"任务逻辑正确、实际执行危险"。
  • 第 2 层 · 执行侧动作保障：STDArm 在模型动作与硬件执行间做运动补偿、时延校准——模型给理想动作，硬件面对真实动态环境（惯量/摩擦/响应延迟），防"想对了、执行偏了"。与数字 Agent 的幂等/事务/输出校验同构。
  • 第 3 层 · 时间尺度分层监控（ROSS 核心招牌）：毫秒级硬安全（碰撞检测/力矩限制/急停，不经任何模型推理）→ 持续监督（轨迹/速度/空间边界高频巡检）→ 任务级判断（继续 / 重新规划 / 触发异常恢复）。设计逻辑：语言模型擅长慢思考，但实时兜底必须运行在更高频率上，模型不参与毫秒级决策。
  • 第 4 层 · 分级异常恢复：中断 → 重试 → 回退 → 替代 Skill → 重新规划 → 人工接管。把一次性"执行失败"转化为可识别、可处理、可恢复的系统状态；失败分类（可重试 vs 需换方案 vs 需人介入）本身是安全判断的一部分。
  • 第 5 层 · 安全经验飞轮：失败案例 / 人工接管 / 异常恢复路径结构化沉淀 → 更新 Skill 安全约束、完善长期记忆、成为训练数据让模型学"什么不该做"。安全知识不是静态规则，是随真实运行持续积累的。

2核心认知

跨本次窗口、可沉淀为判断依据的认知。

安全治理是横切能力，不是单一模块框架印证

数字世界是抽象准则（9 纵 4 横），物理世界是五层实体（ROSS）——两个独立来源指向同一结论：安全必须贯穿每一层，任何"安全模块"的思维都会留下系统性缺口。

安全不做在模型"心中"，做在模型"出口"设计原则

默认模型输出不可信；外层校验（Safe-BeAl/VLA-Stem）将安全层与模型解耦——模型升级、换基座不影响安全层。能力越强越需要出口校验，安全预算独立于模型迭代。

时间尺度分层是具身安全的钥匙核心机制

LLM 擅长慢思考（理解目标/长程规划），但实时控制与安全兜底必须运行在更高频率上。各层级决策放在各自适应的时间尺度：毫秒级硬安全不经模型，任务级判断才用语义理解。

失败分类本身就是安全判断系统设计

一次性"执行失败"被转化为可识别、可处理、可恢复的系统状态；异常恢复链（中断→重试→回退→替代 Skill→重规划→人工接管）是产品能力而非补丁——物理世界没有"免费的重试"。

安全知识是飞轮，不是静态规则数据观

事故/近失/人工接管都成为训练样本，让模型学"什么不该做"。与数字 Agent 的"安全红队 + 失败经验回流"完全同构——安全能力随真实运行单调积累（前提：数据被结构化沉淀）。

谁兜住物理世界安全责任，谁定义市场终局判断

ROSS 把安全做成系统骨架而非功能，正是"责任边界=市场壁垒"在具身域的落地；这也是 Token 终局里"智力 × 责任边界"中责任侧的现实样本。

更强的模型更可能给出"看似合理但物理危险"的动作（尤其长程任务下组合出未预见的物理后果）。ROSS 的选择：不追求模型自觉，靠出口校验兜底——能力与信任在架构上解耦。

数字 Agent 的沙箱/意图防火墙失败成本低、可无限重试；物理世界一次失败可能已造成碰撞损伤。因此物理版 Fallback 必须分级：毫秒级硬安全兜底 + 执行层补偿 + 任务级重规划 + 人工接管兜底。

工业单机 vs 汽车级：ROSS 的边界即 2127 的机会

ROSS 仅覆盖实验室/工业单机场景，未覆盖汽车级约束：ASIL-D 功能安全、多域协同、OTA 合规、长生命周期。这不是缺陷叙事，而是白空间——先回答"五层 × 汽车域改造"的人占据卡位。

智力侧：单步成功率 99.78% 的门槛（天南测算）；责任侧：五层兜底 + 责任承保机制的成熟度。二者谁先到达，决定 Token 终局到来的节奏与卡位顺序。
