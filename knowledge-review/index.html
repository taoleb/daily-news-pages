A. GEO：竞争从"链接位"移到"答案位"（09-07）

来源：09-07 笔记（普林斯顿论文 arXiv 2311.09735 + Answerbit 官网 + 产业实践多篇）
  • GEO = 让品牌被 AI 写进答案正文并引用，而不只是搜索结果排名；量化指标"答案份额"＝提及概率 × 引用权重 × 追问留存率。
  • 数据：微软 2025-10 披露 AI 搜索推荐流量同比 +357%；GEO 报告 2026 称 AI 推荐流量 +527% YoY、转化率约 4.4×（商业口径需打折看）。
  • Answerbit 闭环：每日并行问 5 平台→归因→优化→回测。腾讯有元宝却监测豆包/Kimi——在腾讯判断里，分发层价值高于自家模型输赢。
  • 五层框架：优化对象是 RAG 管线，"被推荐"＝被抓到→被选中→被写进答案三道门；技术上 robots.txt 放行 / llms.txt（至今无厂商背书）/ JSON-LD / SSR；内容上统计+引用+引述单项最高 +40%，作者档案引用率 +47%。
  • 原创判断：GEO 技术层本质是把内容编译成模型信任的格式；与华为 ADS 分层同构——语义权力的争夺落到谁定义可验证的接口。
接口标准的制定权＝答案位的税权——"责任边界=市场壁垒"在营销分发侧的直接同构。

B. Looped Transformer：第三根 scaling 轴的诞生史（09-08）

来源：09-08 笔记（arXiv 1807.03819 / 2502.05171 / 2605.23872 / 2606.18023 / 2607.16051，提交日期已核原文）
  • 第一性问题：堆参数变贵后，计算深度从哪买——同一组权重循环 R 次，参数轴、token 轴之外出现迭代深度这第三根轴；思考搬进潜空间，不占输出带宽、不需 CoT 数据。
  • 辩证链：UT（2018）提出即被堆参数军备竞赛否决 → Recurrent Depth（2025.2）3.5B 打 50B 等效、GSM8K ≈0→34.8 → Training-Free（2026.5）循环=数值阻尼精化，窗口 n=4 甜点、n≥6 悬崖 → LoopCoder-v2（2026.6）18T token 受控实验循环 3 次以上回退 → Loopie（2026.7）layer-loop 优于 model-loop，同算力击败 vanilla 对照。
  • 时间结构观察：2018→2025 沉寂七年、一年走完十年路——范式复活的前提是核算体系变了，不是论文变好了。
  • Astra 证据须分层：已确认仅"9/4 发布全量上线"；"用了 recurrent depth"是 The Information 报道级判断，非 OpenAI 官宣；行为指纹（少 token 换强推理）为独立佐证；"必然已绕过饱和墙"是零证据纯推断。
  • 监控悖论：latent reasoning 的推理在隐状态循环里、不在 token 序列上——CoT 监控看到的只是"说话草稿"，能力藏在不可观测的 R 圈里。
不是没人愿意看，是没有东西可看——监督问题从环境设计层下沉到架构层。

3关键张力（3 项）

两条新线各留一组未收敛对立，外加一组贯穿两者的定位张力。

循环三次回退：墙还是伪影？vs 固定剂量假设

LoopCoder 结论在"代码域+从头预训练+固定 R"下测得；若叠加深度随机采样 + PLT 并行化 + 按输入条件化 R（ACT 回魂），非单调可能只是固定剂量的伪影。

判断："循环三次有害"与"对同一题固定循环三次有害"两命题之差，就是"想多久算多久"能否成立。
内部循环吃掉外部循环？vs harness 定位前提

模型 test-time 深度可伸缩后，harness 层 agent loop（反思/重试/多轮编排）的增量价值边界需重估——直接冲击 2127 自进化 harness 论证的前提。

判断：这是本轮对既有立场最硬的一条修订压力，优先级高于 GEO 观察项。
路线没走完就进场采买vs 剂量问题悬空

Astra 在 LoopCoder 警告（6/16）三个月后、Loopie 合题（7/17）后 49 天发布——OpenAI 要么独立解决了剂量问题，要么没解决但赌其他增益更大；全链条唯一悬空的关键工程问题。

判断：行为指纹≠机制确认，对外引用时保持"报道级"标注纪律。

5待思考问题：两线留下的五个钩子

按与主线（2127 立场 / Agent 自进化）的距离排序，harness 边界问题居首。

1.【前提修订】harness 外部循环的增量价值边界在哪？

若模型内部深度可伸缩，反思/重试/多轮编排哪些仍必须在外层做？这决定 harness 论证要不要改写，是本轮最急的开放问题。

2.【安全学】思考不外化后，监督的替代工作面是什么？

CoT 监控审计的只是输出投影——可验证环境设计需给出架构层答案（如潜空间轨迹可读化工具、干预点），否则安全承诺退化为对训练的置信。

3.【伪影之辩】"两次饱和墙"能否被自适应深度推翻？

社区若确认回退是固定剂量伪影，自适应深度还差什么——第三轴 scaling law（参数×token×迭代最优曲面）目前只有离散点证据。

4.【标准权】模型厂商会不会官方化"引用接口"？

类 Bing 站长工具之于 SEO，谁先做谁拿标准权（国内：元宝/豆包/DeepSeek）；GEO 监测数据反哺自家权重是配套观察点。

5.【2127 观察项】主机厂要不要建"AI 答案位监测"？

成本极低（5 平台每日提问）、行业几乎无人做——汽车分发层 AI 可见度仍是前瞻视角的首选低成本候选。

本轮总判断：GEO 给出语义权力的分发侧样本，Looped Transformer 给出架构侧的监督缺口；两线在"过程不可见"会师，而 harness 边界是必须先收敛的那个口子。
