主题一 · AI Infra「9 纵 4 横」：生产级 Agent 的工程骨架

来源：08-27《AI Infra 全景图：9 层纵向架构 + 4 个横切能力》（公众号 Knock，约 7500 字；工程实践总结，工具对比为 2025-2026 时点快照）
核心断言：绝大多数 Agent 项目停在 Demo 阶段——不是模型不行、不是算法不行，是 Infra 不行。Demo 只需要 L1（模型）+ L4（编排）；生产需要全部 9 层 + 4 横切。
  • 纵向 9 层（L0 基础资源 → L1 模型网关 → L2 数据知识 → L3 Prompt 管理 → L4 编排 → L5 工具执行 → L6 状态记忆 → L7 评测 → L8 可观测）：大多数团队只关注 L4（Agent Framework）+ L2（向量库），忽略其余 7 层——生产稳定性恰恰取决于那些"不起眼"的基础设施。
  • 横向 4 能力贯穿所有层：安全治理、CI/CD 与发布治理（Prompt/模型/RAG/工具全组件版本化）、FinOps 成本归因（Token 计费的工程基础）、开发者体验。
  • 生产 vs Demo 的判别式：每一层都有日志、可追溯、有 Fallback。
  • 三阶段路线：验证期（1-2 周最小闭环）→ 原型期（1-2 月补齐编排/记忆/评测）→ 生产期（全 9 层 + 4 横切 + 发布门禁）。

主题二 · ROSS Harness 安全治理五层：横切安全的物理实体

来源：08-27《ROSS Harness 安全治理五层实践》（灵犀智涌两篇报道拆解，机器之心；公司 PR 口径，无第三方审计）
本质一句话：安全不做在模型"心中"，做在模型"出口"——默认模型可能给出"看似合理但物理危险"的动作。
  • 出口校验层：Safe-BeAl（规划与执行间加安全评估）、VLA-Stem（不改原 VLA 基座、外部附加安全层）、CLMASP（形式化逻辑校验补全任务序列）——防"任务逻辑正确、实际执行危险"，且模型升级不影响安全层。
  • 执行补偿层：STDArm 运动补偿与时延校准——模型给理想动作，硬件面对真实动态环境，防"想对了、执行偏了"。
  • 时间尺度分层监控（ROSS 核心招牌）：毫秒级硬安全（碰撞/力矩/急停，不经任何模型推理）→ 持续监督（轨迹/速度/边界高频巡检）→ 任务级判断（继续 / 重新规划 / 异常恢复）。LLM 慢思考不参与毫秒级决策。
  • 分级异常恢复：中断 → 重试 → 回退 → 替代 Skill → 重新规划 → 人工接管；失败分类（可重试 / 需换方案 / 需人介入）本身是安全判断的一部分。
  • 安全经验飞轮：事故 / 近失 / 人工接管结构化沉淀为 Skill 约束与训练数据——安全知识不是静态规则，随真实运行持续积累。

2核心认知

跨本次窗口、且经受住"第二次阅读"检验的认知。

Demo 陷阱的根因是 Infra，不是模型框架断言

生产级 Agent 需要算力调度、模型网关、数据管道、Prompt 管理、编排、沙箱、记忆、评测、可观测九件事同时成立。选型时应先问"缺哪几层"，而不是"哪个模型 / 哪个框架最强"。

生产与 Demo 的判别式：每层有日志、可追溯、有 Fallback验收标准

这是 9 纵 4 横全篇最可迁移的一句话——数字世界与物理世界（ROSS）通用：任何一层没有日志、追溯或 Fallback，就不算生产级。可作为 2127 各模块的验收底线。

安全不做在模型"心中"，做在模型"出口"设计原则

默认模型输出不可信；外层校验（Safe-BeAl / VLA-Stem 思路）将安全层与模型解耦——模型升级、换基座不影响安全层。能力越强越需要出口校验，安全预算独立于模型迭代。

时间尺度分层：谁在什么频率上做决策核心机制

LLM 擅长慢思考（理解目标 / 长程规划），但实时控制与安全兜底必须运行在更高频率上，模型不参与毫秒级决策。"决策频率分层"是 harness 设计的第一问题，数字 Agent 同样适用（高频校验 vs 低频规划）。

安全知识是飞轮，不是静态规则数据观

事故、近失、人工接管都成为训练样本，让模型学"什么不该做"。与数字 Agent 的"安全红队 + 失败经验回流"完全同构——前提是数据被结构化沉淀。

Infra 是漂移的补偿机制跨笔记印证

呼应 08-23《本地 LLM 变笨》（同模型不同推理栈输出漂移）：漂移是物理事实，L1 模型网关（Fallback）+ L7 评测门禁 + L8 Trace + 横切 CI/CD 是对冲手段——把"模型不稳定"当作工程输入而非事故。

3关键张力

笔记中明确对立或尚未定论之处。

模型能力 vs 模型可信：越强越危险？

更强的模型更可能给出"看似合理但物理危险"的动作（尤其长程任务下组合出未预见的物理后果）。ROSS 的选择：不追求模型自觉，靠出口校验兜底——能力与信任在架构上解耦。

收敛：安全预算独立于模型迭代；外层校验可替换、可升级，不拖累模型演进。
PR 口径 vs 独立验证：框架可信，数据存疑

赛绩（160 分 / 全国第三 / 3.6 倍提升）与工程成熟度全部为灵犀自报，无第三方审计；论文为研究支撑。五层框架值得借鉴，但量化结论在独立复现前不可作为判断依据。

引用标注 PR 口径；把"如何独立验证"纳入 2127 评测体系设计。
数字沙箱 vs 物理世界："拦下来重试"不再免费

数字 Agent 失败成本低、可无限重试；物理世界一次失败可能已造成碰撞损伤。因此物理版 Fallback 必须分级：毫秒级硬安全兜底 + 执行层补偿 + 任务级重规划 + 人工接管兜底。

具身 harness 的 Fallback 设计要求高于数字 Agent 一个量级——这本身是进入壁垒。
工业单机 vs 汽车级：ROSS 的边界即 2127 的机会

ROSS 仅覆盖实验室 / 工业单机（柔性工位），未覆盖汽车级约束：ASIL-D 功能安全、多域协同、OTA 合规、长生命周期。这不是缺陷叙事，而是白空间——先回答"五层 × 汽车域改造"的人占据卡位。

时点快照 vs 快速换代：框架当清单用，选型按评测更新

9 纵 4 横的工具对比是 2025-2026 时点快照，Agent 工具换代极快；且 9 层分法有主观性（记忆/状态可合一、评测/可观测边界模糊）。作为通用框架使用，选型须按实际评测持续更新，引用时标注时点。
