二、主题聚合：五篇都在回答「什么时候做」，答案分成两条相反的箭头

方法：不问五篇讲了什么，只问它们把「约束」和「学习」分别安排在生命周期的哪个时点
主线统一疑问五篇的共同结构
① 约束前移什么时候必须定死？越是一次性、全局、不可逆，越往最早的可改期推
② 学习后移什么时候才开始学？越是可迭代、局部、可回滚，越往最晚的运行期推
③ 双向收税两个方向各付什么代价？前移交「锁死税」，后移交「样本税」

主线①：约束前移——写到最早的那个还能改的时点

  • CED 篇是这条线最典型的自述：把 HBM 带宽、Prefill/Decode 时延特征作为架构的第一性约束，在模型出生的第一天就写进结构——20+20 拓扑、输入 8B／输出 16B、Global KV 压到约 890 bytes/token。
  • 算子篇的刚性基座是同一动作的硬版本：安全判定必须有限步可判定，所以无循环递归、状态空间封闭、越界硬切断（ASIL-D 监控 MCU、Cedar/Rego、eBPF Verifier）。「非图灵完备」的实质就是在设计期把可变性一次剥干净。
  • 算子篇的「一次性代码」策略补上另一半：微内核用形式化证明封死，业务层接受高周转、由 Agent 全量重构。同一系统里，不变的锁进最内层，可变的放到最外层——这是前移原则的组织版表述。
  • 判据由此收敛：凡一次性、全局生效、不可逆的，越早越好。改动成本随阶段递增（设计期最便宜，部署后最贵），前移就是买最便宜的那张票。

主线②：学习后移——改进被推到最晚的运行期

  • Dream-RSI 把学习的时点直接搬到运行期：不改参数、改 Search Policy，以「白天真实探索 + 夜间梦境回放」的双轮驱动持续修补策略。学习不再发生在训练那一天，而是每天都在发生。
  • 存储篇为这种后移提供了资产侧的条件：运行期产生的中间状态被正式确认为已预付成本、可反复复用的资产（KV Cache、Reasoning Trace、Working Memory、Checkpoint），并上了 RTO／RPO 这类正式考核指标——运行期的副产品被纳入了资产负债表。
  • RSI 综述的自主度阶梯给出方向性证据：从 L2 到 L5，人类保留的边界逐级外移，最后只剩物理与安全硬约束；而 B0（CoT、Reflexion、ToT）之所以被定为伪 RSI，正因为它不跨任务留存——不跨任务留存的就不算学习。
  • 判据与前移互为镜像：凡可迭代、局部生效、可回滚的，越晚越便宜。晚做的好处是能拿到更多信息，且做错的代价可被回滚。

主线③：两条箭头各自收一笔税，车端被收两次

  • 前移的代价是锁死税：CED 的 20+20 与 8B／16B 一旦定型，就绑死在「带宽贵、算力便宜」这张当前硬件账本上。账本若反转，偏置就成了负债——架构寿命＝所假设约束的寿命。
  • 后移的代价是样本税：Dream-RSI 自己交了边界，梦境回放只能利用已探索并记录过的分支，无法预测从未涉足的未知分支——它是插值器，改进上限由真实探索能采到的样本封顶。
  • 车端两边都付：安全约束必须前移（不可事后补），而真实探索最难采样（不可高并发复制、代价不可逆）。更尖锐的是——车端的物理与责任约束，是唯一不能靠硬件换代消解的那一类：带宽会变便宜，责任不会。

三、核心认知（本轮跨篇提炼）

  • 「自进化长在外壳上」的深层理由是时间常数匹配，不是权重太贵。权重的时间常数是季度级且更新不可逆，比环境漂移周期还长，闭环根本跑不完一圈；而策略与状态的时间常数短到分钟级，配得上。判据应写作：闭环周期必须短于环境变化周期——这比「不可并行／不可逆／需签字」更根本，因为它是那句判据的来源。
  • 确定性在时间轴上是双向迁移。约束往最早的可改处推（预训练设计期、形式化层），学习往最晚的可回滚处推（运行期、策略层）。两个方向共用同一条判据——可逆性，而不是成本。可逆的进闭环，不可逆的进结构。
  • 架构自由度＝空间 × 时间两个切面。09-17 回答「放哪一层」，本轮回答「什么时候还能改」。两个问题合起来才完整：一个设计点的位置由层级与锁定时刻共同决定，只报层级会漏掉最贵的那一维。
  • 「责任边界＝市场壁垒」得到一条更硬的底座：责任之所以是壁垒，是因为它不可逆。可回滚的动作才允许留在闭环里；不可回滚的动作只能前移到形式化层或留在人手里。于是可逆性与责任是同一个量的两面，而不可逆性既解释了壁垒，也解释了前移。
闭环周期必须短于环境变化周期——这是选场的第一条判据。

四、关键张力（只留未收敛）

张力①：前移锁死的，恰恰是变化最快的那个量

  • 前移原则要求把约束写进最早、最不常改的层；但 CED 前移进结构的是硬件账本（带宽贵、算力便宜），而账本本身是全栈里最善变的量之一——算力单价过去十年就是一路下行。
  • 这就形成一个自相矛盾：把变化最快的量写进最不常改的层。前移本为省未来的改动成本，却可能把未来的一次大改动变成了重训级事故。
  • 未收敛：两条路都说得通——「账本的相对关系比绝对值稳定」（带宽与算力之差或可长期保持），或「应把账本做成可切换参数而非结构偏置」。目前没有判定信号。

张力②：前移这个动作本身不可逆，于是不可逆被叠加了

  • 前移的判据是「不可逆的东西早点定」。但前移这个动作本身不可逆：约束一旦进了设计期，试错就发生在最贵的时点上（改结构＝重训）。
  • 于是出现双倍不可逆：不可逆的内容 × 不可逆的位置。安全侧这恰恰是优点（要的就是改不动），效率侧却是风险（赌错了没有退路）。
  • 未收敛：同一个机制在安全维度是资产、在效率维度是负债，这两个评价能同时成立多久？是否需要给效率侧单独留一条可逆通道（如可热更换的策略层）？

张力③：前移假设「出生即最优」，而后移假设「环境会持续供料」

  • 前移的前提是需求形态稳定：CED 的 20+20 与 8B／16B 建立在 Agent 负载长输入、短输出这一判断上。若负载反转（长输出成为常态），非对称偏置立刻反向。
  • 后移的前提是环境持续供给样本：Dream-RSI 的双轮驱动要求白天那一轮真实探索成立，而车端恰恰不成立。
  • 两个前提都不由技术自身保证——一个依赖负载形态不漂移，一个依赖样本可采集。没有任何一篇给出前提失效后的回退机制，这是本轮唯一完全空缺的板块。

张力④：策略空间饱和之后，后移路线往哪走

  • 后移路线的天花板由 Discovery Tree 的覆盖面决定。策略可以在已记录的树上反复对弈，但插值不能产生新的分支。
  • 一旦策略空间被穷尽，继续后移就不再带来提升——此时唯一出路是回到权重层（前移／重训），也就是必须承认「不动权重」是有期限的。
  • 未收敛：这个交接信号是什么？「回放收益连续 N 轮无增益」足以判定饱和吗，还是必须由外部新样本触发？
承前未收敛（原地保持，不做「看起来有进展」的润色）：循环剂量的判决性实验仍未出现；NBER「顶尖员工提升≈0」仍停在官方摘要级；状态分级判据（可重算缓存 vs 不可丢资产）仍未闭合；模拟器由策略自身生成导致的标尺自指问题仍无独立验证方案。四条本轮均无新证据，原样保留。

五、认知变化

  • 修正 09-17 的结论：那一轮判定「三篇都锁死，只是落点不同」，即「共识是假的、分歧是真的」。加上时间轴后需改写为——分歧在空间轴，共识在时间轴：约束前移与学习后移各自都是单向的，没有任何一篇主张反向。所以五篇的关系不是分歧，而是一套带方向的层次分工。
  • 升格：「不动权重」从成本约束变成时间约束。前几轮把它读成「重训太贵」，本轮读成权重的时间常数配不上任何真实闭环。代价不是钱，是周期——这解释了为什么自进化必然长在外壳上，而不是「碰巧先在外壳上做」。
  • 新增一条来源性判据。「不可并行／不可逆／需签字者挤出闭环」此前是一条并列清单；本轮看出它的上游是闭环周期与环境变化周期的匹配这条更基本的条件，清单三条只是它在具体环节上的展开。
  • 记账项：零新增进入第 1 天，静默不承担论证功能。本轮 5 篇 md5 逐字节未变，全部价值来自换轴重读；不因零新增而放宽入库标准，也不把未收敛项写进对外材料。

六、待思考问题

  1. 闭环周期能否量化成第一条选场判据？如何度量一个系统的改进闭环周期（采集→沉淀→回放→发布）？若闭环周期 > 环境漂移周期，自进化是否只是在追一个已经移走的目标？这个比值能否做成一个进入门槛。
  2. 前移与后移的分界线能否用变更成本曲线判定？设计期与部署后的改动成本差几个数量级，这个量级差有实证吗？是否存在变更成本在部署期反而更低的技术选择（如可热更换的策略层、可远程更新的约束配置）——若存在，前移判据就需要划出例外区。
  3. 架构寿命按什么折旧？CED 这类把硬件账本写进结构的偏置，折旧年限应对齐硬件换代、负载漂移，还是安全认证？三者不等长时以谁为准？
  4. 车端的「白天轮」能否用台架与封闭场地替代？台架是否同时满足可并行复制（多台架并行）与可逆（可重复）两条？若能，车端是不是唯一能同时做到「约束前移」与「样本可采」的折中场景？
  5. 策略空间饱和的判定信号是什么？回放收益连续无增益够不够，还是必须由外部新样本触发？两种迁移在交接点的责任归属如何切——回到权重层意味着重训，谁来签这一次？
  6. 是否存在第三类可逆性：当时可逆、事后不可逆？长周期数据污染、缓慢积累的分布偏移，都属于当下能回滚、后果延迟暴露的情形。若「可回滚即可进闭环」成立，这类动作是否需要单列一档门槛？
