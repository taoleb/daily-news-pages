# AI for Engineering｜智能网联汽车能力矩阵

五大技术域 × 四个研发阶段，20 个能力单元的静态交互网站。

## GitHub Pages 部署

将本目录文件置于专用仓库根目录。在 Settings → Pages 中选择 Deploy from a branch，再选择 main / (root)。保留 .nojekyll。全部资源使用相对路径，可用于项目子路径。

## 功能

组合筛选、搜索、详情分栏、优先级初评、布局收藏、讨论备注、Markdown 导出与演示模式。收藏与备注仅保存在当前浏览器，不上传到 GitHub。

## 内容边界

工程任务与布局机会为研究讨论建议；成熟度与评分为研究初评。案例附官方来源，跨域迁移属于研究设想。

## 隐私

此版本移除了 Sites 专属的私密访问标识，不提供客户端访问控制。个人账号的 GitHub Pages 网站为公开网站；私有源仓库不等于私密网站。原 Sites 私密版本独立保留。
