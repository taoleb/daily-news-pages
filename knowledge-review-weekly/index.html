01GEO：分发层从“链接位”挪到“答案位”

来源：《GEO（生成式引擎优化）知识框架｜腾讯 Answerbit 与实现方法》（2026-09-07 · daily/2026-09-07/ · Answerbit 官网 + 普林斯顿 arXiv 2311.09735 + 产业实践文）

笔记先给出一句定义：GEO 的目标是让品牌被 AI 写进答案正文并被引用，而不只是在搜索结果列表里排名。竞争位从“链接位”移到“答案位”，并造了一个可运算的指标——答案份额＝被提及概率 × 被引用权重（顺带一提 vs 核心证据）× 追问留存率。数据侧：微软广告团队 2025-10 披露 AI 搜索推荐流量同比 +357%；AI 搜索来的用户转化率约传统 organic 的 4.4×（SaaS 面板聚合，属商业口径，须打折看）。

腾讯 Answerbit：本周最锋利的事实锚点

Answerbit 是 AI 搜索可见度监控平台（interest 注册阶段）：每日并行问 DeepSeek、豆包、元宝、Kimi、通义千问 5 家，抓取回答存结构化数据，产出 Visibility Score + 平均位次 + 引用来源分布，闭环四步 Monitor → Analyze → Optimize → Collaborate，首批客户即腾讯系自用。

“腾讯自己有元宝，却建平台监测豆包/Kimi——说明在腾讯的判断里，分发层的价值高于自家模型输赢。”—— 09-07 笔记 · 身份微妙处

实现五层（笔记的可操作部分）

  • 原理层——闯三道门：被抓到（爬虫收录）→ 被选中（检索进 top-k）→ 被写进答案（生成时被引用）。SEO 只管前两道，GEO 全管。
  • 技术层：robots.txt 放行 AI 爬虫（训练与检索访问分开配，很多品牌被墙而不自知，是最高杠杆的 5 分钟修复）；llms.txt 属低成本先占位（无任何大模型厂商承诺固定权重）；JSON-LD Schema.org 降幻觉、强实体识别；SSR/保留 HTML 结构利于 RAG。
  • 内容层：普林斯顿论文实证的三大模型无关策略——加统计数字、加权威引用、加专家引述，单项最高提升来源可见度 +40%，对原本排名差的页面最猛；再加 answer-first、FAQ 化、原子化事实句（“销量3.2万辆”优于“销量遥遥领先”）。
  • 权威层：Wikidata/百科实体登记 + 作者档案，社区实测完整作者信息使引用率 +47%；模型“信谁”靠跨源一致性。
  • 测量层：Answerbit 卖的就是这层——品类 prompt 集 → 每日多模型并行 → 可见度/位次/引用源统计 → 反推引用偏好 → 定制内容 → 发布回测（类 A/B）。
  • 边界与代价：效果 domain-dependent（优化对象是“模型群交集”，本质讨好统计偏好）；可验证性弱于 SEO；军备竞赛已在发生（FAQ 农场、伪造统计），模型厂商反制＝GEO 的 alpha 窗口会关。

本次讨论的原创提炼

GEO 技术层的本质是“把人类内容编译成模型信任的格式”；而定义这套格式的不是内容方，是模型厂商——接口标准的制定权 = 答案位的税权。—— 09-07 笔记 · 核心判断 1、2

第二个原创观察是跨域同构：华为把能力绑硬件、按 SKU 说清责任边界；GEO 把“被推荐”拆成三道门逐门定价——两者都是把黑盒能力拆成可核对承诺的产业化动作，语义权力的争夺最后都落到“谁来定义可验证的接口”。第三个是产业平移：用户问“XX 品牌的车怎么样”时 AI 引了谁，GEO 监测+优化逻辑可整体平移到汽车分发层。

02Looped Transformer：第三根 scaling 轴与监控悖论

来源：《Looped Transformer / Recurrent Depth 技术路线：第三根 scaling 轴的诞生史》（2026-09-08 · daily/2026-09-08/ · PaperAgent《GPT-6 Astra 背后》→ 五篇论文时间轴深挖，提交日期已核 arXiv 原文）

第一性问题：当堆参数的边际收益变贵之后，“计算深度”还能从哪里买？标准 Transformer 的隐含契约是“深度＝层数＝参数（每层权重用一次）”；recurrent depth 的破法是把同一组权重循环 R 次，用迭代次数接管深度——在参数轴、输出 token 轴之外长出第三根 test-time 计算轴。关键差别：它把思考搬进潜空间，不占输出带宽、不需要 CoT 训练数据、不占长上下文。

论文时间角色核心贡献 / 残留问题

链条拉直：UT 提出免费深度 → 被年代否决 → test-time compute 共识让“免费深度”突然值钱 → 民主化（TrainFree）→ 科学化（LoopCoder 敢报负面）→ 资本合法性（Loopie 与堆参数正面对账并赢）。

时间结构里的两个深观察

  • 七年等一扇门，一年走完十年路：2018→2025 沉寂七年，不是思想变快，是外部条件（test-time compute 共识 + MoE 改算力核算 + 大厂撞算力墙）同时满足。
  • Astra 是路线没走完就进场采买的人：LoopCoder“三次回退”警告（6/16）三个月后 GPT-6 Astra 发布（9/4），Loopie 合题后 49 天——要么独立解决了剂量问题，要么赌其他增益更大。
“范式复活靠核算体系变了，不是论文变好了。”—— 09-08 笔记 · 时间结构观察一
