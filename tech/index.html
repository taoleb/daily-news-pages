01 · MiniMax 更新 M3.1 Flash，主打复杂任务能力与成本下降

国内官方
10月19日晚发布；22:54媒体确认 · 北京时间
核心事实：MiniMax 正式更新 M3.1 Flash，称线上推理速度接近前代的3倍、Agent任务综合使用成本下降70%。模型已通过 API、M Plan 和 MiniMax Code 提供，权重将在后续发布。

观察：高频工具调用的竞争同时涉及任务完成率、速度与总成本。

05 · Modal 公布 Vera CPU 沙盒测试，重负载吞吐提升约2倍

国际官方
10月19日22:01（官方首发元数据） · 北京时间
核心事实：Modal 计划将 NVIDIA Vera CPU 用于 Sandboxes，首次从长期使用的x86体系扩展至Arm。其自建测试覆盖50类去除网络调用的编程任务，报告高并发负载下约2倍吞吐提升。

单任务串行测试优势并不总是明显；更大的收益来自拥挤、多租户主机的并发行为。结果由Modal自行测量，不能外推成所有CPU工作负载的统一提升。

观察：Agent运行环境的CPU、内存带宽和调度，正在影响端到端效率。

来源：Modal 工程博客

09 · NVIDIA 在JUPITER完成104量子比特容错计算仿真

国际官方
10月20日02:00（官方RSS） · 北京时间
核心事实：NVIDIA 公布在于利希JUPITER超算上完成104量子比特容错计算仿真，以现实硬件噪声研究magic-state cultivation。项目扩展到8192个GPU，使用cuQuantum和CUDA-Q工具。

公司称该方法相较此前方案所需物理量子比特减少90%。这是经典超算上的仿真验证，不是已经建成同等规模、可用的容错量子硬件。

观察：超算仿真正在为量子纠错方案提供设计反馈，实际硬件仍需后续验证。

来源：NVIDIA 官方 · 交叉核验
