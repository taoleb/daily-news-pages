安全/隐私Chrome 引入设备绑定会话凭据，针对会话 Cookie 窃取

来源：Ars Technica · 原始来源

关键事实：DBSC 将加密密钥保存在设备安全硬件中，浏览器需用设备密钥对会话凭据签名。

Ars Technica 报道，Chrome 新增的 device-bound session credentials 可减少攻击者盗取会话 Cookie 后在另一台浏览器复用登录状态的风险。Windows 使用 TPM，macOS 和 iOS 使用 Secure Enclave 等硬件安全区域；私钥不会被设备释放，单独窃取 Cookie 不能完成挑战签名。

安全Cloudflare：2026年上半年每小时缓解约5343起网络层 DDoS

来源：Cloudflare Blog · 原始来源

关键事实：上半年缓解 2320 万次网络层攻击和 29.64 万亿次 HTTP DDoS 请求；二季度超过 1 Tbps 的网络层攻击有 805 起。

Cloudflare 的半年度报告称，二季度超过 1 Tbps 的攻击数量较一季度增长六倍以上。报告还指出，96.62% 的网络层攻击低于 500 Mbps，90.60% 在 10 分钟内结束，但短攻击仍可能造成路由不稳定、重传和服务降级，因此自动化、持续防护十分重要。

工程/算力研究发布 macOS 虚拟机中的 Apple Silicon LLM 推理加速方案

来源：Cua / GitHub · 原始来源

关键事实：在 M1 Ultra 测试中，TinyLlama 1.1B 在相同虚拟机中提示处理速度提升 11.08 倍、生成速度提升 16.36 倍。

Cua 团队称其研究发布通过一个进程范围的兼容层，解锁 macOS guest 中较新的 Metal 快路径；虚拟机仍使用 Apple 提供的虚拟 GPU。文章还报告 Gemma 4 12B 的提示处理从 71.66 提升至 515.76 token/s，生成从 3.41 提升至 49.67 token/s，但结果受芯片、系统和工作负载影响。

工程/硬件石墨烯透明电极驱动软性可调焦镜片

来源：伦敦玛丽女王大学 · 原始来源

关键事实：研究团队把还原氧化石墨烯超薄透明电极集成到软性镜片驱动层，实现小电场电子调焦。

校方介绍，该原型通过拉伸软膜改变镜片形状，避免传统电调焦镜片的笨重移动部件和不透明边缘电极。研究成果发表于 Advanced Functional Materials，潜在应用包括紧凑型医疗成像、自动对焦相机和可穿戴显示器。研究团队仍需继续优化电极透明度与性能。
