一、AI / 模型与 Agent

Apple 发布 M6 与 M5 Ultra 芯片及新款 Mac，主打本地 AI 算力跃升

官方来源：Apple 新闻室（2026-08-25）

关键事实：Apple 推出 M6 基础芯片与 M5 Ultra，并同步更新 Mac Studio（M5 Max / M5 Ultra）与 Mac mini（M6 / M5 Pro）；新机强调“常开式智能体计算”与本地大模型运行能力。

官方称 M5 Ultra 内部内存带宽约 1.2TB/s，面向本地推理场景。极客公园测算，整机上运行非量化 DeepSeek V4 级别模型可达每秒千级以上预填充、五十级以上生成，已接近云端体验。国行 Mac mini 6999 元起、Mac Studio 19999 元起。

OpenAI 自研推理芯片 Jalapeño 首批测试：能效领先英伟达现行产品

官方来源：OpenAI 官方博客（2026-08-25）

关键事实：在 GPT-OSS 120B、DeepSeek R1 670B、Kimi K2.5 1T 三款模型上，峰值吞吐下单位功耗产出的 AI 工作量是对比系统的 1.5–1.9 倍，端到端延迟低 1.7–3.6 倍；额定 700 瓦，实测持续功耗不超过 550 瓦。

该芯片由 OpenAI 与博通合作开发，对标英伟达 GB300，但官方未与刚出货的 Vera Rubin 比较，也不用于训练。OpenAI 计划年底前在自有算力中部署，第二代在研、第三代设计中。

字节跳动发布「豆包工作」统一办公 Agent，整合 TRAE 与扣子

中国媒体来源：极客公园（2026-08-25）

关键事实：字节正式发布面向生产力场景的 Agent 产品「豆包工作」，可自主拆解任务、调用工具，完成文档/表格/PPT 与多媒体制作，并通过虚拟桌面操作电脑与浏览器；TRAE、扣子团队整体并入豆包体系。

接入飞书后，可调用企业消息、文档、会议与权限等上下文完成周报、方案与经营分析。极客公园指出，字节正从“Chatbot”转向“接受任务、调用工具并交付结果”的生产力产品，回应腾讯 WorkBuddy 跑出的规模化信号。

极客公园观察：大模型公司流行“匿名公测”出海打法，Ox Alpha 引社区竞猜

中国媒体来源：极客公园（2026-08-25）

关键事实：8 月 20 日 OpenRouter 上出现匿名模型 Ox Alpha（100 万 token 上下文、支持图文视频输入、可调用工具、免费），被接入 OpenCode、Hermes 等编程 Agent；社区猜测其与智谱 GLM-5.x 关系密切，但智谱官方尚未认领。

文章梳理 HappyHorse（阿里 ATH）、Pony Alpha（GLM-5 早期版）、Hunter Alpha（小米 MiMo-V2-Pro）、Elephant Alpha（蚂蚁 Ling-2.6-flash）等先例，指出中国团队越来越熟练地把海外开发者平台作为新品第一站。

Qwen 推出 3.8-Flash-Next 混合专家模型，总参数 125B、激活约 6B

官方/社区来源：ModelScope（Qwen 官方，2026-08-25）

关键事实：Qwen 在 ModelScope 与 Hugging Face 上预告 Qwen3.8-Flash-Next，采用混合专家（MoE）结构，总参数约 125B、单次激活约 6B，面向本地与低成本部署。

开发者讨论认为，该规模适合 128GB 内存设备（如 Strix Halo、GB10）及新款 Mac Studio 本地运行；MoE 结构有望在消费级硬件上以接近可用的速度运行。

MiniMax 四款模型上线 GMI Cloud，开放 14 天免费试用

GPT-5.6 Sol 设计 CPU 成功运行《毁灭战士》

国际媒体来源：Tom's Hardware（2026-08-25，经社区频道转引）

关键事实：AI 爱好者 Angel 展示用 GPT-5.6 Sol 设计的定制 CPU“Codex-R32”，在解谜游戏 Turing Complete 的沙盒中成功运行 1993 年游戏《毁灭战士》。

该 CPU 由基础逻辑门搭建，运行基于 C 语言的 PureDOOM 移植版、编译为 RV32IM 机器码在仿真硬件上执行；游戏画面叠加在处理器门级电路的实时脉冲示意图上。属爱好者实验，非产品发布。

二、芯片 / 算力 / 基础设施

英伟达首测 Vera Rubin NVL72，DeepSeek 实测吞吐最高提升 30 倍

官方来源：NVIDIA 博客（2026-08-25）

关键事实：英伟达首次公布下一代机柜 Vera Rubin NVL72 的片上实测数据，以 DeepSeek-V4-Pro 跑智能体编码任务，每兆瓦吞吐量较 GB300 最高提升 30 倍，每百万 token 成本最高下降 35 倍。

同期英伟达量产推理加速芯片 Groq 3 LPX（运行 Gemma 4 31B 输出 3400 token/秒），并发布智能体专用 Vera CPU；马斯克旗下 SpaceXAI 宣布部署 Vera CPU。

英伟达发布 Jetson Orin Nano 2 边缘模块，推理性能翻倍、功耗降 40%

国际媒体来源：The Robot Report（2026-08-25，英伟达发布）

关键事实：英伟达发布入门级边缘 AI 计算机 Jetson Orin Nano 2，算力 78 TOPS、内存 8GB，推理性能较上代 Orin Nano Super 翻倍，同性能下功耗降低 40%。

模块与开发套件将于 2027 年上半年上市，可在边缘侧实时运行 Cosmos、Qwen 3 等大模型；英伟达称超 300 万开发者使用其机器人技术栈，Wing、Matic 正评估或采用。

SiFive 推出首款服务器平台，RISC-V 进军数据中心

专业媒体来源：Chips and Cheese（2026-08-25）

关键事实：SiFive 发布其首款服务器平台，支持双宽 GPU（最高 450W），标志着开源指令集 RISC-V 向正规服务器/数据中心市场迈进。

评论认为，在 RAM/存储涨价与高端 GPU 昂贵的背景下，免授权费的 ISA 在数据中心未必是决定性成本变量，但生态成熟度与驱动仍是落地关键。

SpaceX 拟 2027 年将 Vera Rubin NVL72 送入太空，测试轨道 AI 计算

国际媒体来源：The Register（2026-08-25）

关键事实：SpaceX 计划在 2027 年把一套英伟达 Vera Rubin NVL72 机架级 AI 系统送入轨道，用于验证太空数据中心相关技术；整套系统由 72 颗 Rubin GPU 与 36 颗 Vera CPU 组成，功耗超 100 千瓦。

将此类设备部署到太空还需解决供电、散热、辐射防护与通信等问题；SpaceX 尚未公布具体发射时间、轨道高度及在轨供电冷却方案。

三、工程 / 开源 / 开发者工具

Firefox 157 将默认启用 JPEG XL 图像格式（全平台）

官方

来源：Mozilla 开发平台公告（2026-08-25）

关键事实：Firefox 157 将在所有平台默认启用 JPEG XL（JXL）解码；Chromium 亦在推进基于 Rust 的 jxl-rs 实现。

开发者讨论关注浏览器间格式互操作，例如网站与上传控件不支持 JXL 时的回退体验。JPEG XL 以高压缩率与无损特性受到性能派欢迎。

Grafana 发布 gcx 与 MCP 服务器，面向遥测驱动的智能体开发

中国媒体来源：InfoQ 中文（2026-08-25）

关键事实：Grafana 正式发布 gcx 命令行工具与 MCP（模型上下文协议）服务器，使 AI 智能体能够基于遥测数据（指标、日志、链路）进行查询与推理。

该能力把可观测性数据接入智能体工作流，便于自动化故障定位与运维决策，是当前“可观测性 + Agent”趋势的代表性落地。

EVE Online 启动向 Python 3 的迁移，覆盖 240 万行代码

开发者博客来源：Simon Willison（2026-08-25）

关键事实：运营二十余年的 EVE Online 宣布启动向 Python 3 的迁移，将用 futurize 脚本处理 240 万行代码，并人工复核约 2 万处 Python 2/3 行为差异（如整数除法语义变化）。

该游戏自 2003 年起运行 Stackless Python，2010 年升级至 2.7；其新一代引擎 Carbon 已用开源 scheduler 库替代 Stackless，本次迁移暂未说明如何替换 Stackless。

微软实验系统 Project Aion 曝光：以 Copilot 为核心、无桌面图标

国际媒体来源：Windows Latest（2026-08-25，经社区频道转引）

关键事实：外媒披露微软 2024 年研发的实验系统 Project Aion（又称 Copilot OS）：无开始菜单与桌面图标，以 Copilot 为核心，基于定制版 Edge 与精简版 Windows 内核 Win3，不支持 Win32 应用，需靠 Windows 365 云电脑补足。

泄露文档称其为跨设备“智能体 OS”，支持 AOSP 与 Windows 11，每段对话可生成独立窗口与图标。报道认为该项目大概率不会发布，微软正移除 Windows 11 部分 Copilot 功能。

四、科研 / 安全 / 前沿

MIT 研究：长期用 AI 聊天机器人辅助新闻判断会削弱辨别力

官方/科研来源：MIT Technology Review（2026-08-25）

关键事实：MIT Media Lab 的 Pattie Maes 等人的研究发现，参与者在四周内用聊天机器人辅助评估配对的新闻标题与图片，初期辨别真假的能力较对照组高约 21%，但随使用时间推移这一优势消失甚至逆转。

研究提示，将 AI 作为“新闻真实性裁判”可能带来依赖与判断力下降的风险，呼吁在媒介素养场景中审慎使用。

FDA 批准首款可连续监测血酮与血糖的可穿戴设备

官方来源：美国 FDA（2026-08-25）

关键事实：FDA 授权首款可同时连续监测血酮水平与血糖的可穿戴设备，为糖尿病管理增加一项工具。

评论指出，血酮监测对血糖管理极佳或极差的少数人群更有价值；该设备在儿童 1 型糖尿病患者等场景中具潜在帮助，但报销与可及性仍是推广关键。
