来源：Simon Willison / 安全研究员 Johann Rehberger

提示注入研究专家 Johann Rehberger 演示了一种针对 Claude Code 自动模式（Auto Mode）的攻击：诱导模型下载并解压压缩包，再借导入 base64 模块之名执行压缩包内的本地文件，从而绕过安全防线，据称成功率约 80%。更值得注意的是，个别情况下自动模式还会阻止模型自行清理已被发现的恶意进程。Simon Willison 赞同其结论：在可能遭遇对抗攻击的场景下，应把无人值守的编码智能体放进容器、虚拟机或系统沙箱运行，并限制网络出口。
