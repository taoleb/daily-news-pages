DeepSeek 上线多模态视觉模型，API 可识别图像内容

来源：DeepSeek 官方文档 / InfoQ中文官方文档（已上线）

DeepSeek 在 API 文档中上线 v4-flash-vision-exp 视觉能力，可将图片按尺寸转为 token 与文本一同计费，超长图片会被等比缩放到约 800×800。社区实测其能理解 Playwright 截图，但仍有“读时钟”等细粒度视觉任务失效案例，整体能力尚处实验阶段。
